Automazione Rilascio Certificati & win-acme

Questo portale espone API RESTful moderne che consentono di automatizzare le richieste da script PowerShell, Ansible, cURL o client ACME:

1. Integrazione con win-acme

win-acme è un client ACME per Windows. Per utilizzarlo verso la vostra PKI aziendale senza esporre direttamente la CA:

  • Il portale funge da Registration Authority (RA) intermediaria.
  • I server interni possono eseguire uno script PowerShell di rinnovo automatico schedulato via Windows Task Scheduler senza bisogno di installare componenti DCOM complessi sulle macchine client.

2. Esempio Richiesta Automatica via PowerShell

# Genera CSR locale su IIS o Windows Server
$csr = (Get-Content "C:\cert\request.csr" -Raw)

# Sottometti al Portale PKI via REST API
$body = @{
    CaId = "ca-foresta1"
    TemplateName = "WebServer"
    CsrPem = $csr
} | ConvertTo-Json

$response = Invoke-RestMethod -Uri "https://pki.azienda.lan/api/certificates/request" -Method Post -Body $body -ContentType "application/json"

if ($response.success -and $response.disposition -eq "Issued") {
    $response.certificatePem | Out-File "C:\cert\issued.cer" -Encoding ascii
    Write-Host "Certificato emesso con successo!" -ForegroundColor Green
}
