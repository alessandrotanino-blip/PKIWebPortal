🔍 Validazione Challenge HTTP-01
In reti micro-segmentate o DMZ strette, usare AutoApprove se il server non può contattare i client sulla porta HTTP.
Consente la verifica reale HTTP-01 anche verso server con indirizzi IP privati (10.x, 172.16-31.x, 192.168.x). I controlli anti-SSRF mantengono sempre bloccati loopback (127.0.0.1) e metadata cloud (169.254.169.254). Richiede la compilazione di Domini Emittibili (Allowlist).
Elenco separato da virgole dei domini (o zone DNS) emittibili via ACME; un nome è ammesso se coincide con una voce o è suo subdominio. Obbligatorio con AutoApprove: senza allowlist, la modalità AutoApprove verrebbe rifiutata per evitare l'emissione di certificati per nomi arbitrari. Lasciare vuoto per non imporre restrizioni (modalità Http01).
